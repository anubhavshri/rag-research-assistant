# RAG Research Assistant

A multi-document Retrieval-Augmented Generation (RAG) system using Ollama, LangChain, FAISS, and Streamlit for intelligent research paper analysis.

## Features
- Multi-document querying
- Semantic search
- Local LLM inference using Ollama
- Streamlit interface
- Research paper analysis

## Tech Stack
- Python
- LangChain
- Ollama
- FAISS
- Streamlit
