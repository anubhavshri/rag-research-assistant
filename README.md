# 🧠 RAG Research Assistant

A multi-document Retrieval-Augmented Generation (RAG) system built using Ollama, LangChain, FAISS, and Streamlit for intelligent research paper analysis and contextual question answering.

---

## 🚀 Overview

This project enables users to upload and analyze multiple research papers simultaneously using a local Large Language Model (LLM) pipeline.

The system performs:
- Semantic document retrieval
- Context-aware question answering
- Multi-document analysis
- Local inference using Ollama
- Interactive querying through Streamlit

Designed as an experimental AI system focused on research-oriented document intelligence workflows.

## ▶️ Running the Project

### 1. Clone Repository

```bash
git clone https://github.com/anubhavshri/rag-research-assistant.git
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Start Ollama

Make sure Ollama is installed and running locally.

### 4. Run Streamlit App

```bash
streamlit run app.py
```
